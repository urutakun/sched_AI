# 🧠 SchedAI

✨ **SchedAI** is a smart class scheduling and management web application built with **Laravel**, **Inertia**, and **React**.
Designed to help schools automate schedule creation, bookings, and role-based management. 🚀

---

## 🌟 SchedAI — Feature List

##### 👤 User & Role Management

- 🔐 Role-based authentication (Admin, Instructor, Student)

- 🧾 Registration and secure login system

- 👥 Admin can manage user accounts and roles

- 🧭 Redirects users to dashboards based on their roles

- 🧱 Middleware protection for restricted routes

#### 🏫 Class Scheduling System

- 📅 Automatic and manual class schedule creation

- 🕒 Time slot management for each subject or session

- 🧮 Conflict detection to avoid overlapping schedules

- 📊 Class overview with filter by department and year level

#### 🎓 Student & Instructor Modules

- 🧑‍🏫 Instructor dashboard to view and manage class schedules

- 🎓 Student dashboard to view personal schedule and announcements

- 📨 Notification system for updates and changes
